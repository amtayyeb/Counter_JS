# Counter_JS

A simple counter built with HTML, CSS and JavaScript.

**Live demo:** https://amtayyeb.github.io/Counter_JS/

## Features
- Add, subtract and reset buttons
- Choose the step size (add or subtract 1, 5, 10 and so on)
- Green number above 0, red number below 0
- Keyboard shortcuts: Arrow Up (add), Arrow Down (subtract), R (reset)
- The number is saved, so it stays after you refresh the page

## Files
- `index.html` the page structure
- `style.css` the design
- `app.js` the logic

## Built with
HTML, CSS, JavaScript (DOM, events, localStorage)
